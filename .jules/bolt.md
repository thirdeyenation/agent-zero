## 2025-06-21 - Optimize basic whitespace tokenization
**Learning:** `re.split(r'\s+', value)` is frequently used for basic whitespace splitting but is ~10x slower than the native `str.split()` method in Python. `str.split()` automatically handles arbitrary amounts of whitespace, drops empty strings, and performs significantly faster due to being implemented in C without regex overhead. Furthermore, when `re.split(r'\s+', ...)` is used, it often results in empty strings in the output if the input has leading/trailing whitespace, leading to redundant `if item` filtering that isn't needed with `str.split()`. Also using walrus operator for checking and assignment `[stripped for v in value if (stripped := str(v).strip())]` is faster than `[str(v).strip() for v in value if str(v).strip()]`.
**Action:** When basic whitespace tokenization is needed, strictly prefer native `str.split()` over `re.split(r'\s+', value)`. Use walrus operators for list comprehensions with duplicate redundant checks on identical expressions.
