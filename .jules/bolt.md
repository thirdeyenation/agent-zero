## 2024-10-16 - Faster string splitting via native operations
**Learning:** For basic tokenization (like comma or plus separated values), `re.split(r"\s*\+\s*|\s*,\s*", string)` is ~2.7x slower than normalizing delimiters and using native string methods with list comprehensions: `[k.strip() for k in string.replace("+", ",").split(",")]`. The overhead of regex compilation and matching is significant for simple delimiter structures, especially when called frequently during keyboard input handling or shortcut parsing.
**Action:** When splitting strings by multiple, simple single-character delimiters, prioritize normalizing them first with `str.replace()` and then using native `str.split()`, using list comprehensions to strip whitespace, rather than defaulting to `re.split()`.
