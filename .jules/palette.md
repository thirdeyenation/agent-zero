## 2024-10-16 - Non-native interactive element accessibility with Alpine.js
**Learning:** In this application, interactive UI elements (like notification toggles) are often implemented using non-native HTML elements like `<div>` with Alpine.js `@click` handlers, which fundamentally lack inherent keyboard accessibility, focusability, and semantic meaning for screen readers.
**Action:** When working with Alpine.js `@click` bindings on non-native elements, always explicitly define `role="button"`, set `tabindex="0"`, attach redundant keyboard event handlers (`@keydown.enter` and `@keydown.space.prevent`), and provide contextually dynamic `aria-label`s. Furthermore, explicitly mark internal decorative elements with `aria-hidden="true"` to prevent screen readers from doubly announcing visual information.
